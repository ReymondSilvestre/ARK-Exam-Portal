Add a faculty / teacher account

Only you can create teacher accounts for this school. Teachers then create the accounts of their own advisory students.

Username = Employee No. (with the school code). Temporary password = birth year + first letter of the last name (example 1985D). The teacher must choose a new password at first sign-in. If you enter the teacher's real email, the account is created with that email: they can still sign in with school code + Employee No., and Forgot your password? sends the reset link to that email.
