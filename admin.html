Add a teacher

Teachers can also create their own account from the sign-in page. Students are added by their teacher.

A one-time temporary password is generated. The teacher must replace it at first sign-in.

Password reset requests

Teachers ask for a reset from the sign-in page. Check the match, then send the reset link to the email on the account. The link is sent only to the registered address, never to whatever was typed in the request.
