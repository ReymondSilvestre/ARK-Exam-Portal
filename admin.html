Add a faculty / teacher account

Only you can create teacher accounts for this school. Teachers then create the accounts of their own advisory students.

Username = Employee No. (with the school code). Temporary password = birth year + first letter of the last name (example 1985D). The teacher must choose a new password at first sign-in.

Password reset requests

Teachers ask for a reset from the sign-in page with the school code and Employee No. Check the match, then reset the password to the temporary one (birth year + first letter of the last name) and give it to the teacher in person.
